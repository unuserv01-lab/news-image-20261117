One image that sums up the world's news of Tuesday 17 November 2026: a newspaper front page, THE WORLD LEDGER, with 45 verified stories from six continents. Lead: the US strikes Iran as the Hormuz tanker war escalates. Second: the first-ever Trump–Xi–Putin trilateral summit, Ukraine striking the Crimean Bridge, and the COP31 draft deal. A world map marks the day's flashpoints, a markets strip carries Brent crude and gold, and the grid covers world, politics, markets, tech, sport and culture — every headline checked against reporting from 16–17 November 2026. The program is a deterministic one-line copy: it writes the image to /output/entry.png, byte for byte identical on every run, with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
